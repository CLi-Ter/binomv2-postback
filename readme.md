# BinomV2-Postbacks
Библиотека содержит:
- [x] Интерфейсы сущностей:
  - [x] Event - событие трекера + набор событий.
  - [x] Conversion - конверсия, статусы, выплата
  - [x] Payout - выплата конверсии, значение+валюта.
  - [ ] Postback - комбинация конверсии и событий.
- [x] Интерфейсы постбек-клиентов 
  - [x] EventClient - отправка событий в трекер.
  - [x] PostbackClient - отправка постбеков и конверсий.
  - [x] Client - общий клиент реализующий все остальные варианты интерфейсов клиентов.
- [x] Клиент для отправки постбеков и событий.
  - [x] Запуск без выполнения запроса.
  - [x] Логгер запросов.
  - [x] Опции для запросов.
  - [x] Поддержка отмены-контекста.
  - [x] Переназначение Tracker хоста для запроса.
  - [x] Переназначение Tracker click url для запроса.
  - [x] Отправка событий
  - [x] Отправка-изменение конкретного события в трекере.
  - [x] Отправка постбека
  - [ ] Отправка BaseClick
  - [ ] Установка LandingPageClick
  - [ ] Отправка клика (?)
